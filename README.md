# GamerFest

Bienvenido a **GamerFest**, una plataforma integral diseñada para la comunidad gamer. Nuestro objetivo principal es ofrecer un espacio centralizado donde los usuarios puedan descubrir nuevos lanzamientos, organizar sus calendarios de juegos, gestionar sus favoritos y mantenerse al día con todo lo relacionado al mundo de los videojuegos.

## Características

- **Lanzamientos**: Descubre los últimos juegos lanzados y explora información detallada.
- **Calendario**: Mantén un registro ordenado de los próximos juegos que saldrán al mercado.
- **Favoritos**: Guarda y gestiona tu lista personal de videojuegos preferidos.
- **Administración**: Panel completo para administrar los datos de la plataforma (solo para usuarios con rol de administrador).

## Tecnologías Utilizadas

Este proyecto fue desarrollado bajo un enfoque full-stack utilizando:

### Frontend
- **React**: Librería principal para la interfaz de usuario.
- **Vite**: Entorno de desarrollo rápido y empaquetador.
- **CSS Vanilla**: Estilización pura y moderna con variables CSS y diseño responsive.
- **React Router Dom**: Enrutamiento de páginas.
- **Lucide React**: Biblioteca de iconos.

### Backend
- **Node.js y Express**: Para la creación de la API y manejo de rutas del servidor.
- **MySQL y Sequelize (ORM)**: Gestión y modelado de la base de datos relacional.
- **BcryptJS y JSON Web Tokens (JWT)**: Para la autenticación y seguridad de usuarios.
